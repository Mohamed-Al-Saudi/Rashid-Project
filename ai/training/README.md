# Model training workflow

Add training scripts here after the dataset and deployment runtime are agreed.

For each model, document:
- dataset source and permission;
- class labels;
- train/validation/test split;
- metrics (precision, recall, confusion matrix);
- false-positive and false-negative examples;
- input image dimensions;
- model size and quantization;
- target-board inference latency and RAM use.

Do not report accuracy alone. For alerts, false alarms and missed waste events are both important.
